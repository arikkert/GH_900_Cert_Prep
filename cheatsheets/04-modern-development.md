# Domain 4 Cheatsheet: Modern Development

## Codespaces

- Lifecycle: create, start, stop, delete.
- `devcontainer.json` defines environment.
- Typical location: `.devcontainer/devcontainer.json`.
- Key fields: `image`, `features`, `postCreateCommand`, `forwardPorts`.

## Actions

- Workflows, jobs, steps, runners.
- GitHub-hosted vs self-hosted runners.
