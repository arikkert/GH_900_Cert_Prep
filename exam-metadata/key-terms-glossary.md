# GH-900 Key Terms Glossary

Definitions of GH-900-level concepts and platform features.

---

## A

**Actions**
GitHub automation platform for workflows defined in `.github/workflows/`.

**Artifacts**
Files generated during a workflow run that can be downloaded later.

---

## B

**Branch**
An independent line of development in Git.

**Branch Protection**
Rules that enforce checks and reviews before merging.

---

## C

**Codespaces**
Cloud-hosted development environments based on containers.

**CODEOWNERS**
File that assigns code ownership and required reviewers for paths.

**Copilot**
AI coding assistant for suggestions and code completion.

---

## D

**Dependabot Alerts**
Notifications about vulnerable dependencies.

**Dependabot Security Updates**
Auto-created PRs that fix vulnerable dependencies.

**Dependabot Version Updates**
Auto-created PRs that keep dependencies current.

---

## G

**GFM (GitHub Flavored Markdown)**
Markdown with GitHub-specific extensions like task lists and tables.

**Gist**
Shareable snippet repository (public or secret).

**GitHub Actions**
Workflow automation platform.

**GitHub Pages**
Static site hosting for repositories.

**GitHub Packages**
Package registry for containers and language packages.

---

## I

**Issue**
A trackable unit of work in GitHub.

**Internal Repository**
Visible to all enterprise members, not public.

---

## M

**Merge**
Combines changes from one branch into another.

**Milestone**
A group of issues or PRs tied to a release goal.

---

## P

**Pull Request**
A request to merge changes with review and checks.

---

## R

**Release**
A Git tag plus release notes and assets.

**Repository**
A project container that stores code, history, and settings.

**Ruleset**
Policy framework for enforcing branch or tag rules.

---

## S

**Secret Scanning**
Detects leaked credentials in a repo's history.

**SSH Key**
Authentication mechanism for Git operations.

---

## W

**Workflow**
A GitHub Actions automation defined in YAML.
