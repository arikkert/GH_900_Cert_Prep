# GH-900 Exam Objectives - Domain Breakdown (Draft)

**Exam**: GH-900: GitHub Foundations
**Version**: Drafted from public GH-900 study guidance - verify before exam.

---

## How to Use This Checklist

Use each objective as a study checkpoint. When you can explain and apply each objective confidently, you are ready for the exam.

---

## Domain 1 - Introduction to Git and GitHub (22%)

### 1.1 Git and GitHub Basics
- Explain Git vs GitHub
- Describe repository structure and common workflows
- Distinguish fork vs clone

### 1.2 Accounts and Visibility
- Compare user accounts, organizations, and enterprises
- Explain repo visibility: public, private, internal

### 1.3 GitHub Products and Tools
- Describe Codespaces, Copilot, Packages, Pages, Gist
- Explain GitHub Desktop, CLI, and Mobile

### 1.4 Documentation and Core Files
- Use GitHub Flavored Markdown
- Describe README purpose and common sections
- Identify `.github/` directory conventions

---

## Domain 2 - Working with GitHub Repositories (8%)

### 2.1 Content Lifecycle
- Create, commit, and review changes via PRs
- Compare merge strategies and when to use each

### 2.2 Releases and Tags
- Distinguish lightweight vs annotated tags
- Create releases and attach assets

### 2.3 Content Review and History
- Use compare view, blame, and file history
- Resolve merge conflicts in GitHub UI

### 2.4 Wikis and Gists
- Create and organize wiki pages
- Use gists for sharing code snippets

---

## Domain 3 - Collaboration Features (30%)

### 3.1 Pull Requests and Reviews
- Open and update pull requests
- Request and respond to reviews
- Choose merge methods for collaboration goals

### 3.2 Issues and Discussions
- Create and triage issues with labels and milestones
- Use discussions for Q and A or long-form threads
- Convert discussions to issues and mark answers

### 3.3 Collaboration Signals
- Use mentions, assignees, and watchers
- Link issues and PRs for traceability
- Interpret repository activity signals

---

## Domain 4 - Modern Development (13%)

### 4.1 GitHub Actions Basics
- Define workflows, jobs, steps, and runners
- Identify common workflow triggers
- Understand workflow permissions and `GITHUB_TOKEN`

### 4.2 Runners and Execution
- Compare GitHub-hosted vs self-hosted runners
- Understand when to choose each runner type

### 4.3 Codespaces
- Describe Codespaces use cases and lifecycle
- Explain `devcontainer.json` purpose and location
- Understand basic billing and usage limits

---

## Domain 5 - Project Management (7%)

### 5.1 Projects and Planning
- Use Projects (v2) board, table, and roadmap views
- Configure fields, filters, and groupings
- Understand project permissions and visibility

### 5.2 Milestones and Reporting
- Create milestones with due dates
- Track progress through issue and PR status

---

## Domain 6 - Privacy, Security, and Administration (10%)

### 6.1 Authentication and Access
- Explain passwords, PATs, SSH keys, and passkeys
- Distinguish OAuth Apps vs GitHub Apps
- Describe org-level 2FA enforcement

### 6.2 Security Features
- Explain Dependabot alerts, security updates, version updates
- Describe secret scanning and push protection
- Introduce code scanning and CodeQL at a high level

### 6.3 Policies and Vulnerability Handling
- Use `SECURITY.md` and private vulnerability reporting
- Explain security advisories and disclosure basics
- Describe dependency graph and SBOM

### 6.4 Repository Protection
- Explain branch protection vs rulesets
- Describe CODEOWNERS and review enforcement

---

## Domain 7 - Benefits of the GitHub Community (10%)

### 7.1 Community Standards
- Explain README, CONTRIBUTING, CODE_OF_CONDUCT, LICENSE roles
- Describe community health files location and purpose

### 7.2 Open Source Collaboration
- Describe open source contribution workflows
- Explain forking and contributing through PRs
- Identify best practices for respectful collaboration
