# Lab 07 - Benefits of the GitHub Community

## Goal

Apply community standards and open source workflows.

## Steps

1. Add a LICENSE and CODE_OF_CONDUCT.
   - Screenshot: `labs/assets/07-01-license-coc.png`
   - Expected output: Files visible in repo root.

2. Add CONTRIBUTING.md and issue templates.
   - Screenshot: `labs/assets/07-02-contributing.png`
   - Expected output: Contribution guidance displayed.

3. Create a discussion to gather feedback.
   - Screenshot: `labs/assets/07-03-discussion.png`
   - Expected output: Discussion topic created.

4. Fork the repo and open a PR from your fork.
   - Screenshot: `labs/assets/07-04-fork-pr.png`
   - Expected output: PR from fork appears in upstream repo.

5. Review stars, forks, and watchers.
   - Screenshot: `labs/assets/07-05-signals.png`
   - Expected output: Community signals visible.

## Expected Outcomes

- You can identify community health files.
- You can explain open source contribution flow.
