# Lab 06 - Privacy, Security, and Administration

## Goal

Enable core security features and review alerts.

## Steps

1. Enable Dependabot alerts and security updates.
   - Screenshot: `labs/assets/06-01-dependabot.png`
   - Expected output: Dependabot features enabled.

2. Enable secret scanning (if available).
   - Screenshot: `labs/assets/06-02-secret-scanning.png`
   - Expected output: Secret scanning enabled.

3. Review and dismiss a sample alert.
   - Screenshot: `labs/assets/06-03-alert.png`
   - Expected output: Alert state updated with reason.

4. Add `CODEOWNERS` and require code owner review.
   - Screenshot: `labs/assets/06-04-codeowners.png`
   - Expected output: PR requires code owner review.

5. Add `SECURITY.md` and enable private reporting.
   - Screenshot: `labs/assets/06-05-security-policy.png`
   - Expected output: Security policy visible in repo.

## Expected Outcomes

- You can locate security settings and alerts.
- You can explain secret scanning, Dependabot, and CODEOWNERS.
