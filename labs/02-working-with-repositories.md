# Lab 02 - Working with Repositories

## Goal

Practice the full PR workflow, compare changes, and create a release.

## Steps

1. Create a branch and edit a file.
   - Screenshot: `labs/assets/02-01-branch.png`
   - Expected output: New branch with changes.

2. Open a pull request with a summary.
   - Screenshot: `labs/assets/02-02-pr.png`
   - Expected output: PR opened with diff and description.

3. Request a review and leave a comment.
   - Screenshot: `labs/assets/02-03-review.png`
   - Expected output: Reviewer assigned and comment logged.

4. Resolve a merge conflict in the web editor (if applicable).
   - Screenshot: `labs/assets/02-04-conflict.png`
   - Expected output: Conflict resolved and marked as fixed.

5. Merge using squash merge and create a release tag.
   - Screenshot: `labs/assets/02-05-merge-release.png`
   - Expected output: PR merged, tag created.

## Expected Outcomes

- You can explain PR steps, merge methods, and tagging.
- You can navigate compare view and blame.
