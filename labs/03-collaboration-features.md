# Lab 03 - Collaboration Features

## Goal

Use PRs, reviews, issues, and discussions to collaborate.

## Steps

1. Create an issue for a change.
   - Screenshot: `labs/assets/03-01-issue.png`
   - Expected output: Issue created with title and labels.

2. Create a branch and open a PR.
   - Screenshot: `labs/assets/03-02-pr.png`
   - Expected output: PR opened and linked to issue.

3. Request a review and add a comment.
   - Screenshot: `labs/assets/03-03-review.png`
   - Expected output: Review requested and feedback logged.

4. Convert a discussion into an issue.
   - Screenshot: `labs/assets/03-04-discussion.png`
   - Expected output: Discussion converted to issue.

5. Merge the PR using squash.
   - Screenshot: `labs/assets/03-05-merge.png`
   - Expected output: PR merged and issue closed.

## Expected Outcomes

- You can explain PR flow and review mechanics.
- You can use issues and discussions together.
