# Lab 01 - Introduction to Git and GitHub

## Goal

Create a repo, configure basics, and validate key UI features.

## Steps

1. Create a new repository with README and license.
   - Screenshot: `labs/assets/01-01-create-repo.png`
   - Expected output: Repo created with README and LICENSE files.

2. Add a description and topics.
   - Screenshot: `labs/assets/01-02-repo-about.png`
   - Expected output: About section shows description and topics.

3. Enable Discussions.
   - Screenshot: `labs/assets/01-03-enable-discussions.png`
   - Expected output: Discussions tab appears.

4. Create a release.
   - Screenshot: `labs/assets/01-04-release.png`
   - Expected output: Release listed with tag and notes.

5. Review Insights > Traffic.
   - Screenshot: `labs/assets/01-05-traffic.png`
   - Expected output: Traffic chart visible (may show zero data for new repos).

## Expected Outcomes

- You can identify where key repo settings live.
- You can describe repo visibility, releases, and insights.
