# Lab 05 - Project Management

## Goal

Use issues, projects, and discussions to plan and track work.

## Steps

1. Create an issue with labels and assignee.
   - Screenshot: `labs/assets/05-01-issue.png`
   - Expected output: Issue created with labels.

2. Create a Projects (v2) board and add the issue.
   - Screenshot: `labs/assets/05-02-project.png`
   - Expected output: Issue appears in the project board.

3. Add custom fields and a status automation.
   - Screenshot: `labs/assets/05-03-fields.png`
   - Expected output: Status auto-updates when PR merges.

4. Create a discussion and mark an answer.
   - Screenshot: `labs/assets/05-04-discussion.png`
   - Expected output: Answer marked in Q and A discussion.

5. Create a milestone and link issues.
   - Screenshot: `labs/assets/05-05-milestone.png`
   - Expected output: Milestone progress shows open and closed counts.

## Expected Outcomes

- You can explain how projects and discussions work together.
- You can interpret milestones and progress.
