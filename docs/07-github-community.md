# 07 - Benefits of the GitHub Community

## Open Source Basics

- Licenses define how code can be used.
- Forks enable community contributions.
- Stars and watches signal interest and updates.

## Community Standards Files

| File | Purpose |
| --- | --- |
| README.md | Project overview |
| CONTRIBUTING.md | Contribution guidance |
| CODE_OF_CONDUCT.md | Expected behavior |
| SECURITY.md | Vulnerability reporting |
| LICENSE | Legal usage terms |

## Contribution Flow

- Fork -> branch -> PR -> review -> merge.
- Use issues and discussions to coordinate.
