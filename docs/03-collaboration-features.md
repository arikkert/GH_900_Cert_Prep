# 03 - Collaboration Features

## Pull Requests

- Open a PR from a branch.
- Request reviewers and address feedback.
- Use merge strategies: merge, squash, rebase.

## Issues and Discussions

- Issues track work and bugs.
- Discussions support Q&A and long-form topics.
- Convert discussions to issues when needed.

## Notifications and Mentions

- Use `@mentions` to alert users or teams.
- Manage notification preferences by repo.

## Merge Conflicts

- Resolve locally for complex conflicts.
- Use GitHub web editor for simple conflicts.

## UI and CLI Workflows

Open a PR (CLI):

```bash
gh pr create --title "Update docs" --body "Summary"
```

Review a PR (UI):

- `Files changed` -> add comments -> approve or request changes.
