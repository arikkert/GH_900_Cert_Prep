## Issues and Milestones

- Use labels for triage and priority.
- Use milestones for release or sprint tracking.

## UI Workflows

Create a project:

- `Projects` -> `New project` -> choose view.

Add issue to project:

- Issue sidebar -> `Projects` -> select project.
